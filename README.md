# 西安交通大学 计算机组成专题实验：RISC-V CPU 设计与实现

![RISC-V CPU](https://img.shields.io/badge/RISC--V-CPU-blue)
![Verilog](https://img.shields.io/badge/语言-Verilog-orange)
![状态](https://img.shields.io/badge/状态-已完成-brightgreen)

基于RISC-V指令集的CPU设计与实现，包含五级流水线和四路组相联缓存。

## 项目简介

本项目实现了一个基于RISC-V指令集的多周期CPU，主要特性包括：

- **五级流水线**：IF（取指）、ID（译码）、EX（执行）、MEM（访存）、WB（写回）
- **四路组相联缓存**：1KB大小，四路，16个组，块大小16字节
- **冒险处理**：实现数据冒险和控制冒险的处理机制
- **支持指令集**：add, sub, addi, ori, sw, lw, beq, bne, blt, bge, bltu, bgeu, jal, jalr, lui, auipc等RISC-V基本指令

## 系统结构

CPU的整体数据通路包括以下主要模块：

- **寄存器文件**：32个通用寄存器
- **ALU**：算术逻辑单元，支持基本运算操作
- **指令存储器**：存储程序指令
- **数据存储器**：存储数据，包含四路组相联缓存
- **控制单元**：生成控制信号
- **流水线寄存器**：各级间的寄存器
- **转发单元**：解决数据冒险
- **分支预测单元**：解决控制冒险

## 主要模块

### 1. 顶层设计 (CPU_Datapath)

集成了所有模块，实现了完整的CPU功能和流水线控制。

### 2. 指令存储器 (IMem)

负责存储和读取指令，通过硬盘中的.dat文件加载指令集。

### 3. 寄存器文件 (RegFile)

实现32个通用寄存器，支持读写操作。

### 4. 算术逻辑单元 (ALU)

支持加、减、与、或、异或、位移等多种运算操作。

### 5. 控制逻辑单元 (ControlLogic)

解码指令，生成各种控制信号。

### 6. 立即数生成器 (ImmGen)

从指令中提取并生成立即数。

### 7. 分支比较器 (BranchComp)

比较两个寄存器的值，用于分支指令的判断。

### 8. 数据存储器 (DMem)

包含四路组相联缓存和主存，负责数据的读写。

### 9. 四路组相联缓存 (FourWaySACache)

实现了LRU替换算法的缓存，包含有效位、脏位等管理。

## 💾 指令测试

1. **基本指令测试**：测试add、sub、ori、sw、lw、beq、lui等指令

## 关键特性实现

### 数据冒险处理

当指令之间存在数据依赖时，通过转发机制解决：
- 前递EX阶段至ID阶段
- 前递MEM阶段至EX阶段
- 前递WB阶段至ID/EX阶段

### 控制冒险处理

采用简单的分支预测策略，假设不采取分支。若分支条件成立，则将IF和ID阶段的指令替换为NOP（气泡）。

### 缓存实现

- 1KB大小，四路组相联
- 采用LRU替换算法
- 写回策略，脏位记录
- 地址划分：Tag(4位) + Index(4位) + Offset(4位)
